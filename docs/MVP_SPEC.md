# 殘響日誌 Aftertone — MVP 功能規格書

> 把每天的殘響，留下成一幅畫。

## 1. 專案定位

**殘響日誌 Aftertone** 是一個將耳鳴紀錄轉化為「每日視覺意象」的私人 PWA。本文件已依 [開發計畫](DEVELOPMENT_PLAN.md) 的 2026-10-02 決策更新；細部同步與安全規則以開發計畫為準。

使用者每次記錄耳鳴事件後，系統會從 Prompt 類別中隨機抽取一類，依照本次紀錄產生對應的描述片段。一天之中記錄次數越多，累積的 Prompt 越完整。

日期結束後，使用者可以將所有片段組合成繁中與英文的完整 Prompt，複製到外部圖像工具，並將產生的圖片上傳至個人收藏；圖片也可稍後補上。

本專案的核心不是鼓勵增加紀錄次數，而是：

- 降低耳鳴紀錄的負擔。
- 將不舒服的身體經驗轉譯為創作素材。
- 讓每天留下的不只是症狀數字，而是一幅屬於當天的意象。
- 保留可回顧的耳鳴事件資料與每日作品。

> Aftertone 為個人紀錄與創作工具，不提供醫療診斷或治療建議。

---

## 2. MVP 目標

第一版聚焦五件事：

1. 快速記錄每次耳鳴事件。
2. 每次紀錄後抽取一個 Prompt 類別並產生片段。
3. 累積並組合當日 Prompt。
4. 編輯並複製中英兩份完整 Prompt，在外部工具生成圖像。
5. 建立每日作品，稍後可上傳或替換一張原圖，並回顧對應紀錄。

MVP 暫不處理：

- 公開帳號註冊及多人使用。
- 內建圖像生成與翻譯 API。
- 社群功能。
- 排行榜、成就、連續登入。
- 健康風險評分。
- AI 醫療判斷。
- 複雜統計報表（輕量的「回望」頁已列入，見 [回望頁規格](superpowers/specs/2026-10-05-insights-page-design.md)）。
- 多人資料共享。

## 3. 核心使用流程

### 3.1 記錄一次耳鳴

1. 使用者點擊「記錄一次耳鳴」。
2. 填寫本次耳鳴狀態。
3. 儲存事件。
4. 系統從尚未取得的 Prompt 類別中隨機抽取一類。
5. 根據本次事件資料產生一段 Prompt。
6. 顯示本次新增的意象片段。
7. 更新今天的 Prompt 狀態。

### 3.2 查看今日意象

使用者可以隨時查看：

- 今日已記錄次數。
- 已取得的 Prompt 類別。
- 尚未取得的類別。
- 今日所有 Prompt 片段。
- 目前組合出的 Prompt 草稿。

### 3.3 結束今天

使用者在該日期結束後，主動按下「完成今日意象」。今天只可預覽，昨天或更早的未完成日期可以補做。

系統：

1. 整理當天所有 Prompt 片段。
2. 若部分類別尚未取得，以最低限度的預設描述補足。
3. 組合中英兩份可分別編輯、複製的完整 Prompt。
4. 保存今日標題及 Prompt，立即建立一筆待圖片作品。
5. 使用者在外部工具生成圖像，回來上傳一張原圖，或日後再補上。

### 3.4 回顧收藏

收藏頁以每日作品為主。

點開作品後可查看：

- 日期。
- 今日標題。
- 圖片或待上傳狀態。
- 繁中與英文完整 Prompt。
- 當日耳鳴次數。
- 當日事件摘要。
- 原始耳鳴紀錄。

## 4. 耳鳴事件紀錄

### 4.1 必填欄位

| 欄位 | 選項 |
| --- | --- |
| 發生時間 | 自動記錄，可手動調整 |
| 耳側 | 左耳 / 右耳 / 雙耳 |
| 強度 | 1～5 |
| 聲音類型 | 高頻 / 低頻 / 嗡聲 / 尖銳 / 脈動感 / 其他 |
| 持續時間 | 短暫 / 30 秒內 / 1 分鐘內 / 1～3 分鐘 / 3 分鐘以上 |

### 4.2 選填欄位

當下狀態可複選：

- 壓力高。
- 疲勞。
- 睡眠不足。
- 安靜環境。
- 使用耳機後。
- 工作後。
- 睡前。
- 其他。

另外提供簡短備註欄。

### 4.3 設計原則

一次紀錄應盡量在數秒內完成。

首頁需將「記錄一次耳鳴」設為最主要操作，不要求使用者先進入日誌或填寫長表單。

## 5. Prompt 系統

### 5.1 基本類別

MVP 使用七個主要類別：

1. **人物特徵**
2. **服裝**
3. **背景**
4. **氛圍**
5. **構圖**
6. **色調**
7. **姿勢 / 動作**

這七類共同構成每日圖像的基本骨架。

### 5.2 抽取規則

當日尚未取得全部七類時：

- 每次新增耳鳴紀錄，從「尚未取得的類別」中隨機抽取一類。
- 同一類別在七類集滿前不重複抽取。

當七類全部取得後：

- 後續紀錄改為抽取「細節擴充類別」。

細節擴充可包含：

- 光影。
- 材質。
- 飾品。
- 特殊物件。
- 粒子 / 視覺元素。
- 情緒細節。

因此耳鳴紀錄較少時，當日畫面會保持片段感；紀錄較多時，圖像描述自然會變得更完整，但介面不使用「升級」、「獎勵」或鼓勵增加耳鳴次數的表述。每段規則式片段同時保存繁中與英文版本，片段列表唯讀；離線新增後若同步時發生主要類別衝突，依穩定順序重分配並提示使用者。

## 6. Prompt 生成規則

Prompt 片段由「抽中的類別」與「本次耳鳴狀態」共同決定。

MVP 可以先使用規則式映射，不依賴 LLM。

### 6.1 人物特徵

可參考：

- 耳側。
- 強度。
- 聲音類型。

例如：

- 高頻 → 清冷、透明、纖細的視覺特徵。
- 低頻 → 沉穩、厚重、較深色的視覺特徵。
- 強度較高 → 特徵更鮮明。
- 雙耳 → 對稱或雙重元素。

### 6.2 服裝

可參考：

- 持續時間。
- 疲勞程度。
- 壓力狀態。

例如：

- 短暫 → 輕便、簡潔。
- 持續較久 → 多層次、包覆感。
- 疲勞 → 柔軟、寬鬆。
- 壓力高 → 結構感、束縛感較強。

### 6.3 背景

可參考：

- 發生時間。
- 當下狀態。
- 是否處於安靜環境。

例如：

- 深夜 → 房間、窗邊、夜色。
- 工作後 → 書桌、螢幕、室內光源。
- 安靜環境 → 空曠空間、薄霧、走廊。
- 聲音尖銳 → 訊號、線條、數位空間。

### 6.4 氛圍

可參考：

- 壓力。
- 疲勞。
- 當日累積次數。

例如：

- 低壓力 → 安靜、柔和。
- 壓力高 → 緊繃、封閉。
- 疲勞 → 朦朧、恍惚。
- 當日累積較多 → 增加重複、迴盪、層疊感。

### 6.5 構圖

可參考：

- 左 / 右 / 雙耳。
- 強度。
- 當日事件數。

例如：

- 左耳 → 偏左或向左的構圖。
- 右耳 → 偏右或向右的構圖。
- 雙耳 → 中央、對稱。
- 強度低 → 留白較多。
- 強度高 → 畫面距離較近。

### 6.6 色調

可參考：

- 聲音類型。
- 強度。
- 發生時間。

例如：

- 高頻 → 冰藍、銀白、淡紫。
- 低頻 → 墨藍、灰綠、棕灰。
- 尖銳 → 較高對比。
- 悶脹 / 低沉 → 低彩度、霧灰。
- 深夜 → 冷色與暗色比例提高。

### 6.7 姿勢 / 動作

可參考：

- 強度。
- 持續時間。
- 疲勞狀態。

例如：

- 強度低 → 靜坐、站立、望向遠方。
- 強度高 → 輕扶耳側、閉眼、側頭。
- 持續較久 → 倚靠、抱膝、停留。
- 疲勞 → 坐在窗邊、伏案、靠牆。

## 7. 每日 Prompt 成長

### 1～2 次紀錄

以碎片式意象為主。

例如：

- 冷色調。
- 深夜窗邊。

### 3～5 次紀錄

逐漸形成角色、場景與情緒。

### 6～7 次紀錄

七個主要 Prompt 類別逐漸完整，可形成完整圖像描述。

### 8 次以上

增加細節擴充片段，例如：

- 微弱光暈。
- 半透明訊號絲線。
- 漂浮粒子。
- 特殊材質。
- 光影變化。

這只是 Prompt 完整度規則，不呈現為遊戲分數或健康狀態評價。

---

## 8. 最終 Prompt 組合

系統以繁中與英文分別依固定順序組合。兩份完整 Prompt 可獨立修改、複製與保存，修改一份不自動覆蓋另一份：

1. 人物特徵。
2. 服裝。
3. 姿勢 / 動作。
4. 背景。
5. 構圖。
6. 色調。
7. 氛圍。
8. 額外細節。
9. 統一風格描述。

範例：

> 一位氣質安靜、略帶疲憊感的銀白長髮女性，穿著柔軟寬鬆的淺色外衣，輕扶耳側、微微閉眼。她站在深夜房間的窗邊，畫面採偏左留白的半身構圖。整體為低飽和冰藍與銀灰色調，氛圍安靜、朦朧、略帶疏離感，空氣中漂浮著細微半透明訊號絲線。唯美細膩插畫，柔和光影，夢境感，大量留白。

MVP 先使用固定的基礎畫風，以確保每日作品放入收藏後具有一致性。

---

## 9. 今日作品

每天完成 Prompt 後立即建立一筆作品資料，圖片可空；每日期最多一張原圖，後續可補上、替換或刪除。

作品包含：

- 日期。
- 今日標題。
- 原圖路徑或待上傳狀態。
- 中英完整 Prompt 與系統草稿。
- 當日耳鳴事件數。
- Prompt 片段。
- 紀錄摘要。

每日標題可由系統從當日片段產生，例如：

- 《微光殘響》
- 《深夜右側》
- 《靜音之前》
- 《第七次回聲》

## 10. 圖像收藏

收藏頁是 Aftertone 的主要長期回顧介面。

### 10.1 畫廊模式

以作品為主，每張作品卡顯示：

- 日期。
- 標題。
- 圖片或待上傳佔位。
- 當日紀錄次數。

### 10.2 詳情模式

點開圖片後顯示：

- 完整圖片或待上傳狀態。
- 日期與標題。
- 繁中與英文完整 Prompt。
- Prompt 片段來源。
- 當日事件摘要。
- 原始事件列表。

### 10.3 月曆模式

收藏頁可在畫廊與月曆之間切換。月曆一次顯示一個月，以週日開始，日期格依狀態呈現：

- 作品：已完成且有圖片，格子顯示圖片縮圖；點一下先出現預覽卡，再點進入詳情。
- 待加入圖片：已完成但還沒有圖片，以虛線格與「＋」標示，點擊進入詳情加入圖片。
- 未完成：有紀錄但尚未完成意象，以 1–3 個小點提示有紀錄，點擊進入日期頁完成意象。

沒有紀錄的日子只顯示淡色日期；今天另以內框標示。詳細規格見 [收藏頁設計規格](superpowers/specs/2026-10-04-archive-gallery-design.md)。

## 11. 頁面規劃

MVP 共四個主要頁面。

### 11.1 首頁

顯示：

- 今日日期。
- 今日紀錄次數。
- 「記錄一次耳鳴」主按鈕。
- 今日已取得與尚未取得的片段類別。
- 最近取得的意象片段。
- 今日意象入口。
- 未完成的過去日期入口與收藏入口。
- GitHub 登入及同步狀態；未登入者不可查看日誌。

### 11.2 記錄頁

提供耳鳴事件欄位。

送出後顯示：

- 本次抽中的類別。
- 新增的 Prompt 片段。
- 今日目前已有的類別。

### 11.3 今日意象頁

顯示：

- 今日事件數。
- 已取得 / 尚未取得的 Prompt 類別。
- Prompt 片段列表。
- 組合後中英 Prompt 草稿；過去日期可分別編輯與複製。
- 僅對昨天及更早的未完成日期顯示「完成今日意象」按鈕。
- 已完成時顯示圖片或待上傳狀態。

### 11.4 收藏頁

顯示所有已完成的每日作品，包含沒有圖片的作品，並可進入作品詳情及上傳、替換或刪除圖片。

## 13. 介面文案原則

Aftertone 不將耳鳴次數包裝成獎勵。

避免：

- 「恭喜解鎖！」
- 「再一次就能升級！」
- 「今日收集完成！」
- 連續登入或紀錄 streak。
- 分數、排行榜。

建議：

- 「今天的意象多了一塊碎片。」
- 「新增了一段描述。」
- 「畫面逐漸形成。」
- 「留下了今天的一部分聲音。」
- 「完成今天的意象。」

## 14. MVP 技術方向

前端：

- Vue 3
- Vite
- Pinia
- Vue Router

登入、儲存與同步：

- GitHub OAuth 登入，伺服端核對指定帳號；未登入不可取得資料。
- Vercel 私人 API 與私人 GitHub 倉庫的獨立資料分支；瀏覽器不持有 GitHub 寫入憑證。
- IndexedDB 離線副本、待同步佇列與連線後自動同步。

本版不內建圖像生成。使用者複製 Prompt 至外部工具，再回來上傳原圖。網站直接上傳限制約 4 MB，較大原圖依固定日期路徑手動放入資料分支並重新同步。

## 16. MVP 完成條件

當使用者可以完整走完以下流程，即視為 MVP 成立：

> 發生耳鳴  
> → 快速記錄  
> → 得到一段意象描述  
> → 同一天多次紀錄逐步形成 Prompt  
> → 完成今日 Prompt  
> → 複製中英 Prompt 到外部工具<br>
> → 完成作品並在稍後上傳圖片<br>
> → 圖片與當日紀錄進入私人收藏

這條流程是 Aftertone 第一版最重要的產品閉環。
