# 抽取動畫「落光 × 漣漪」設計規格

日期：2026-10-04
互動原型：[docs/ui-concepts/prompt-draw-demo.html](../../ui-concepts/prompt-draw-demo.html)（以 dev server 開啟 `http://localhost:5173/docs/ui-concepts/prompt-draw-demo.html`）
相關文件：[MVP 規格](../../MVP_SPEC.md)、[UI 設計規劃](../../UI_DESIGN_PLAN.md)

## 1. 目的與原則

使用者保存一筆耳鳴紀錄後，系統會抽出一個 Prompt 類別並產生片段（MVP_SPEC §5.2）。目前結果頁直接切換成結果卡，沒有任何過場。這個動畫讓「從七類之中被選出一段意象」有一個安靜的瞬間。

設計原則：

1. **不做獎勵感。** 觸發動畫的是一次耳鳴，介面不能讓人覺得「抽中了」很值得慶祝（MVP_SPEC：不使用升級、獎勵或鼓勵增加耳鳴次數的表述）。所以不用彈跳、閃爍、加速後減速停格的拉霸節奏，全程緩入緩出。
2. **用顏色揭曉類別。** 光點一開始是中性的灰藍，落地後染上類別色。被染上的顏色就是答案，不另外打出「抽中」的字樣。
3. **動畫只是裝飾。** 結果在保存完成的當下就已經確定並可讀取；動畫不影響資料，任何時候都能跳過。

## 2. 時間軸

基準速度下全長約 5 秒；卡片與文字在 4.6 秒時已完全可讀，之後只剩最後一圈漣漪淡出。下表的時間都以保存成功、結果畫面出現的那一刻為 0。

| 時間 | 階段 | 內容 |
|---|---|---|
| 0–2.6s | 落光 | 只顯示「已保存於此裝置」。灰藍光點從這行字下方 22px 出現，邊飄落邊從 0.3 倍長到 1 倍，左右擺動（振幅 46px，越接近落點越收斂）。光點周圍與軌跡上偶爾亮起四角星形的稜鏡微光。 |
| 2.5–3.4s | 觸及・染色 | 光點落在卡片中心，輕輕一沉（放大到 1.28 倍再回到 1.1 倍）。光點從灰藍漸變成類別色。 |
| 2.6–5.0s | 漣漪 | 四圈波紋依序擴散（間隔 230ms，每圈 1.7s）。每圈出生時偏灰藍，擴散到一半時染成類別鮮明色；後面的圈起始就更接近類別色。底下同時暈開一片類別色柔光。漣漪外圍散落 7 個微光，依序閃一下。 |
| 3.25–4.55s | 浮現 | 標題「今天的意象多了一段描述。」和卡片從模糊（blur 8px）中對焦；類別圖片從 1.08 倍縮回原尺寸並淡入；卡片邊框在後半段從淡灰藍漸變成類別鮮明色。標籤、中文、英文依序對焦（間隔 160ms）。 |
| 3.9–4.6s | 歸位 | 光點縮小到 0.45 倍，飄進類別標籤前的小圓點後消失，同時標籤圓點出現。 |
| 4.35–4.85s | 操作 | 「查看當日意象／再記一筆」按鈕淡入。 |

曲線：飄落用逐格計算的路徑（線性插值）；其餘使用 `ease-in-out` 或 `cubic-bezier(.3,.7,.3,1)`。不使用 overshoot 或 bounce。

## 3. 視覺規格

### 3.1 顏色

每個核心類別有三個顏色。前兩個已存在或由此規格新增為 CSS 變數：

| 類別 | 底色 tint（既有 `--category-*`） | 鮮明色 vivid（新增 `--category-*-vivid`） |
|---|---|---|
| 人物 person | `#b7c7d9` | `#869eb9` |
| 服裝 clothing | `#e8cbd8` | `#ca8097` |
| 背景 background | `#b8dce3` | `#84bbc6` |
| 氛圍 atmosphere | `#d4c7e8` | `#a992cb` |
| 構圖 composition | `#eadfae` | `#d0c076` |
| 色調 color | `#c8dec7` | `#98bd96` |
| 姿勢 pose | `#ebc5a9` | `#d29a71` |

- **鮮明色的推導：** 保留 tint 的色相，飽和度 × 0.8 + 0.02，亮度 − 0.16。數值直接寫成變數，執行時不計算。
- **用途：**
  - tint：卡片頂部柔光、漣漪底下的暈染、標籤底色
  - vivid：光點外圈、漣漪線條、卡片邊框、標籤小圓點
- **灰藍起始色：** 光點 `#9aabc2`。
- **標籤文字：** 用 `--text`（`#34445D`）。原型中標籤文字用的是 tint 混灰的顏色，在淡色底上對比不足，正式版不沿用。

### 3.2 細節擴充類別

七類集滿後抽到的光影、材質、特殊物件沒有專屬色與圖片。這三類：

- tint 用 `#c9d6e6`，vivid 用 `--outline`（`#8fa8c8`），與灰藍起始色同一系，染色的變化較小但仍成立。
- 卡片不放類別圖片，只保留頂部 tint 柔光。

### 3.3 光點與微光

- 光點直徑 22px，徑向漸層：白色核心 → 顏色 → 透明；外加兩層光暈。灰藍層與類別色層疊在一起，以交叉淡入淡出完成染色。
- 微光：四角星形（SVG path），12–16px，填色為白或極淡的藍、紫、青，帶 2px 淡藍 drop-shadow。每次閃爍 0.8–0.9s：縮放 0.2 → 1 → 0.3，旋轉 0° → 45°。
  - 光點周圍 8 個，距中心 30–48px，飄落途中各閃 3 次。
  - 軌跡上 7 個，在路徑兩側 14–32px，光點經過時閃 1 次。
  - 漣漪外圍 7 個，距中心 55–100px，落地後依序閃 1 次。

### 3.4 結果卡

- **類別圖片：** 使用 `public/images/categories/{category}.webp`。圖片佔卡片上方 40% 高度，`background-size: cover`，遮罩為由上而下的漸層（95% → 60% → 0%），視覺上大約到 1/3 處淡完，文字落在淡化後的區域。
- **邊框：** 動畫結束後為 1px 類別 vivid 色。
- **標籤：** 前方的 8px 圓點是光點歸位的終點，顏色為 vivid。

## 4. 實作結構

### 4.1 元件

新增 `src/components/PromptReveal.vue`，負責結果卡與動畫，`RecordView.vue` 只把結果交給它。

```
<PromptReveal :fragment="result.fragment" :date="result.event.date" @again="..." />
```

- **輸入：** `fragment: PromptFragment`、`date: string`。
- **輸出：** `again` 事件，給「再記一筆」使用。
- **內容：** 原本 RecordView 的結果區塊（eyebrow、標題、結果卡、兩個按鈕）移進這個元件。動畫圖層（光點、漣漪、微光）放在元件內一個 `pointer-events: none` 的絕對定位層。
- **動畫實作：** 使用 Web Animations API（`element.animate`），和原型相同。這樣可以統一 `finish()` 跳過，也不需要額外套件。元件卸載時 `cancel()` 所有動畫。
- **路徑計算：** 光點的起點與終點用 `getBoundingClientRect` 在 mount 後量測：起點是 eyebrow 下方，落點是卡片中心，歸位點是標籤圓點。

### 4.2 樣式

- 新增的 class 寫進 `src/style.css`，沿用現有的 token 與命名方式。
- 在 `:root` 新增七個 `--category-*-vivid` 與細節類別的兩個顏色。
- 卡片以 `data-category` 或 class 取得對應的 tint、vivid 與圖片，不在 JS 裡寫死顏色。

## 5. 跳過、減少動態與無障礙

- **跳過：** 點擊或觸控結果區任一處，或按 Esc，所有動畫立即 `finish()`，直接呈現最終狀態。動畫進行中按鈕尚未出現，所以點擊結果區不會誤觸其他操作。
- **減少動態：** `prefers-reduced-motion: reduce` 時不建立光點、漣漪與微光；標題、卡片、按鈕以 220ms 淡入一次出現。
- **螢幕閱讀器：** 結果區有 `aria-live="polite"` 的文字，資料確定時立即朗讀「已保存。新增意象：{類別}，{中文片段}」，不等動畫。動畫圖層全部 `aria-hidden="true"`。
- **焦點：** 動畫結束（或跳過）後，焦點移到結果卡標題，鍵盤使用者可以接著 Tab 到按鈕。
- **重複記錄：** 每次「再記一筆」後保存都會重新播放完整動畫。使用者可隨時點擊跳過；本版不加「記住跳過偏好」的設定。

## 6. 驗證

- **單元測試（vitest）：** vivid 色對照表涵蓋全部七個核心類別，細節類別會落到中性色。
- **元件行為：**
  - 在 reduced motion 下不建立動畫圖層節點
  - `finish` 後所有元素達到最終狀態（不透明度 1、邊框為 vivid）
  - 卸載時沒有殘留的動畫
- **瀏覽器實測：** 375px 與 1280px 各跑一輪全部七類與一個細節類別。用原型的方式快轉時間軸，逐段確認落點和歸位點的座標正確、文字可讀。
- **效能：** 動畫只使用 transform、opacity、filter 與漣漪的 width／height，在一般手機上不應掉幀。若漣漪的 width／height 動畫造成卡頓，改用 SVG circle 的 `r`。

## 7. 不在本次範圍

- 音效與震動回饋。
- 首頁「今日意象」七圓與本動畫的連動（例如光點飛回首頁圓圈）。
- 日期頁、收藏頁的任何動畫。
