入口頁歡迎動畫：四種方向

每個畫面都只放品牌、標語和「用 GitHub 登入」。按「重播」可以重新看一次。

A｜聲波漣漪擴散

Aftertone
殘響日誌

把今天的殘響，
輕輕留在這裡。

中央一點，漣漪一圈圈往外擴散後淡出，持續循環。最貼近「耳鳴／殘響」的主題，也跟回望頁的耳朵漣漪同一套語言。

B｜標題逐字浮現


品牌名與標語一個字一個字從模糊中浮現，播完一次就停住，最後登入按鈕出現。畫面最乾淨，像翻開日記的第一頁。

C｜窗光呼吸

Aftertone
殘響日誌

把今天的殘響，
輕輕留在這裡。

沿用首頁的窗光照片，光影緩慢明暗、微微飄移，像清晨坐在窗邊。最安靜，但因為用了首頁的背景，區隔感最弱。

D｜漣漪 + 標題組合


先只有漣漪在畫面中央擴散，接著往上讓位，品牌與標語逐字浮現，最後才出現按鈕。最有儀式感，但約 6 秒後才能按登入。

D + C：窗光背景上的漣漪與標題

同一套動畫，兩種節奏。比較看看要等多久才出現登入按鈕比較舒服。

E1｜原速（按鈕約 5 秒出現）


漣漪先在窗光裡獨自擴散約 2 秒，再讓位給文字。儀式感完整，但每次打開都要等一下。

E2｜快版（按鈕約 2.5 秒出現）


漣漪一出現就開始讓位，文字緊接著浮現。氣氛一樣，但不太需要等。
